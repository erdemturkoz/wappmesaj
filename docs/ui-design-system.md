# Wapp Mesaj UI Design System

## Principles

1. Operational clarity over decoration.
2. High contrast status communication.
3. Consistent controls and predictable spacing.
4. Mobile-first responsive behavior.
5. No coupling between visual components and campaign logic.

## Tokens

- Background: slate 950 / slate 900 surfaces
- Primary action: emerald
- Informational: sky
- Warning: amber
- Destructive: rose
- Radius scale: 12px, 16px, 24px
- Spacing scale: 4px base grid

## Components

- Application shell
- Top navigation
- Panel and elevated panel
- Primary, secondary and destructive controls
- Field, textarea and select
- Status badge
- KPI card
- Progress indicator
- Empty state
- Modal dialog
